## 已实现

- 移除原来的 raw/source 数值驻留缓存、`processed_cache`、`cacheDays` 及下一训练窗预热，改为以编码后的 Dataset X/Y/W 为主要跨训练日缓存。FP4 只压缩 X 存储，解码批次仍是普通浮点张量。
- 固定训练窗口下 Dataset 跨训练原位滚动。X/Y/W 预留 `ComboTrainDataset.column_slack`（默认 10%）空列；默认股票选择下股票集合变化时原地左移并按代码重排列，新增股票在保留日期写编码 0/Y=0/W=False，只读取尾部新日期；超出容量时先释放旧 Dataset 再完整构建，避免两份完整训练集共存。该做法依赖「股票不在基础股票池时特征为 0、目标无效」的数据契约。
- 优化批量数据读取、预测窗口缓冲、`rank`/`zscore` 和回测的重复收盘价/基准数据读取。`rank` 后续修复了 CPU float16 长轴名次生成的精度回归，并添加回归测试。
- `runEval` 已按此前要求拆分直接日频 `run/read` 与其他路径；本轮未扩展任何新评估模式。
